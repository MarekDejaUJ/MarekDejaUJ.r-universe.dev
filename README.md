# Pakiety seminarium licencjackiego EPI

Rejestr r-universe pakietów powstających na seminarium licencjackim
(elektroniczne przetwarzanie informacji, Instytut Studiów Informacyjnych UJ).
Pakiety budują się z gałęzi głównej repozytoriów autorów.

Serwis: <https://marekdejauj.r-universe.dev>

```r
install.packages("IndeksH",
                 repos = c("https://marekdejauj.r-universe.dev",
                           "https://cloud.r-project.org"))
```
